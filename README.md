# Portfolio Dashboard

A powerful, interactive Streamlit application for analyzing and visualizing personal stock portfolios. This dashboard intelligently parses broker CSV files (specifically designed to handle ICICIDirect formats alongside standard formats) and enriches them with historical market data from Yahoo Finance to provide deep insights into your portfolio's performance, inflation-adjusted returns, and benchmark comparisons.

## ✨ Features

- **Summary & Transaction Analysis**: Upload your broker's Summary and Transactions CSVs. The app auto-detects column names and handles complex numeric formats (like parenthesis negatives `(5.3)` and currency symbols `₹1,00,000`).
- **Interactive Column Mapping**: If auto-detection fails, manually map your CSV columns via the UI.
- **Auto-Ticker Correction**: Broker symbols (e.g., `HINCOP`) are automatically identified and mapped to standard Yahoo Finance `.NS` or `.BO` tickers using Yahoo's search API. Custom mappings are saved locally in `ticker_map.json`.
- **Portfolio Allocation (Overview)**: Visualize your stock distribution weighted by market value, color-coded by Unrealized P/L%.
- **Aging & Real Returns**: Calculates inflation-adjusted (Real) returns and CAGR for each holding period (grouped into <1yr, 1-3yr, >3yr buckets) using historical India CPI data from the World Bank API.
- **Benchmark Alpha**: Compares each stock's performance against major indices (NIFTY 50, NIFTY 500, SENSEX) from the exact date of purchase to calculate Alpha.
- **Heatmaps**:
  - **Buy Heatmap**: Visualizes the amount of capital (₹) deployed month-by-month over the years.
  - **Performance Heatmap**: A compact grid showing the percentage return of every currently held stock.
- **Dual-Axis Growth Chart**: Reconstructs your historical portfolio value day-by-day based on transaction history and plots it against the actual historical movement of the NIFTY 50 index.

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed. The project relies on several key libraries:
- `streamlit`
- `pandas`
- `plotly`
- `yfinance`
- `numpy`

### Installation

1. Clone or download this repository.
2. Initialize and activate your virtual environment (e.g., `streamlit_env`).
3. Install the required packages:
   ```bash
   pip install streamlit pandas plotly yfinance numpy
   ```

### Running the App

Run the following command in your terminal from the project root directory:

```bash
streamlit run dashboard.py
```

The application will open automatically in your local web browser (typically at `http://localhost:8501`).

## 📁 Required Data Files

The dashboard requires two CSV files exported from your broker to unlock all features:

1. **Summary CSV**: Your current holdings.
   - *Required data*: Stock Symbol, Company Name, Quantity, Value At Cost, Value At Market Price, Unrealized P/L %.
2. **Transactions CSV**: Your historical buy/sell orders.
   - *Required data*: Date, Stock Symbol, Type (Buy/Sell), Quantity, Price.

*Note: The app is resilient and will attempt to auto-map varying column headers (e.g., "P/L %" vs "Unrealized Profit/Loss").*

## ⚙️ Configuration Files

- `ticker_map.json`: Autogenerated file that stores custom mappings between your broker's internal stock symbols and Yahoo Finance tickers. You can manually edit this file or use the `⚙️ Settings -> 🔄 Ticker Corrections` UI in the dashboard.
